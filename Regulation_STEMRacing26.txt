 Module Descriptions

 1. Document Ingestion Module
- Parse PDF files using PyPDF2, PDFPlumber, or similar
- Extract text content with metadata
- Extract images (CAD renderings, graphs, tables)
- Count pages, detect sections
- Structure detection (headings, tables, images)

 2. Deterministic Check Module
- Page Limit Check: Verify against portfolio requirements
- Section Detection: Search for required sections by heading or content
- Element Presence: Detect images, tables, graphs, CAD files
- Terminology Detection: Keyword matching for engineering and project management terms
- Format Compliance: Check file naming, page size, PDF quality
- Reference Detection: Citation presence and formatting

 3. AI Evaluation Module

 3.1 NLP Quality Analysis
- Model Type: Large Language Model (LLM) fine-tuned on STEM education content
- Evaluation Tasks:
  - Content relevance to judging criteria
  - Coherence of technical reasoning
  - Depth of engineering justification
  - Innovation assessment
  - Professional tone
  - Evidence completeness
  - Linkage between sections

 3.2 Visual/Image Analysis
- Model Type: Vision Transformer (ViT) or similar
- Evaluation Tasks:
  - CAD image quality
  - Graph/chart clarity
  - Visual consistency across portfolio
  - Branding application
  - Layout professionalism

 3.3 Comparative Analysis
- Model Type: Rule-based + AI combination
- Evaluation Tasks:
  - Cross-section consistency
  - Iteration tracking
  - Evidence completeness
  - Design improvement progression

 4. Scoring Engine
- Apply scoring rubrics per criterion
- Calculate weighted scores
- Generate confidence scores for AI-based evaluations
- Aggregate totals per portfolio
- Produce final scores

 5. Output/Report Module
- Generate score reports per portfolio
- Provide criterion-by-criterion feedback
- Show confidence levels
- Identify improvement areas
- Export to database
